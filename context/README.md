# context/ — what a Claude session should read first

Rebuilt twice a day by the GitHub workflow (~5:17 AM and ~2:43 PM ET). Always newer than any copy uploaded to a project.

- `overview_and_rules.md` — where everything lives, how grading works, the rules (hand-maintained)
- `pick_record.md` — every recommended pick and result, lessons (update after each tally)
- `model_accuracy.md` — SIGNAL vs the book, measured effects (auto)
- `team_board.csv` — 30 teams, ATS/OU splits, every stat for/against with rank (auto)
- `player_baselines.csv` — every player's averages, spread, minutes, starts (auto)
- `today.txt` — which slate projections.json / grades.json are for (auto)
